# Cosmetics Data Analysis in R

**Author:** Naishvi Shah  
**Dataset Source:** [Kaggle - Sephora Products and Skincare Reviews](https://www.kaggle.com)  
**Language:** R  

---

## Overview
Exploratory data analysis of 1,472 Sephora cosmetics products using R.
This project explores product categories, pricing, ratings, and skin type 
suitability to uncover patterns in the cosmetics industry.

---

## Report
A full visual report has been created showing all analyses with charts and 
outputs. The report file `cosmetics_report.html` can be found in this repository
and includes all code alongside visual results.

---

## Analysis Includes
- Product count by category
- Average price by category
- Average rating by category
- Price distribution across all products
- Number of products suitable per skin type
- Price vs. rating correlation
- Top 10 highest rated products
